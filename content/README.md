# Content

Files here ship as they are in the package's folder. `content/mortar/tv/clip.mp4` installs as
`plugins/<Author-Mod>/mortar/tv/clip.mp4`, where Mortar-Television reads it. The other kinds are `mortar/posters`,
`mortar/tips`, `mortar/paintings` and `mortar/boombox`. This file is left out of the package.
